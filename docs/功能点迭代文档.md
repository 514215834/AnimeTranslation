## 1. 迭代总览

| 里程碑 | 版本 | 主题 | 预估周期 | 核心目标 |
|---|---|---|---|---|
| M1 | v0.1 | MVP：单集"生肉→中文字幕"闭环 | 2~3 周 | 跑通主流程，可用可部署 |
| M2 | v0.2 | 字幕工程与翻译质量 | 3~4 周 | 质量与批量能力达到"字幕组半成品"水平 |
| M3 | v1.0 | 人工复核工作台与团队协作 | 4~6 周 | 人机协同闭环，团队可用 |
| M4 | v1.x | 生态与开放能力 | 持续 | 插件 / API / CLI / 多语言 |
| Backlog | — | 远期池（含 AI 配音——暂不规划） | — | 详见第 7 节 |

> 说明：AI 配音支线（人声分离 + 声音克隆 TTS）经 2026-10-02 评审结论为**暂不规划**，架构仅保留扩展点，本迭代文档不含其功能点。

## 2. M1 · MVP：单集字幕翻译闭环（v0.1）

| ID | 功能点 | 描述 | 优先级 | 验收标准 | 依赖 |
|---|---|---|---|---|---|
| F-M1-01 | 项目与剧集管理 | 创建番剧项目、添加剧集、上传本地视频（mp4/mkv），FFmpeg 解析时长/分辨率/音轨并展示 | P0 | 上传 24min 视频后 10s 内显示元信息；项目/剧集可增删改查 | — |
| F-M1-02 | 音频抽取与预处理 | FFmpeg 抽取音轨，重采样为 16k 单声道 wav 供 ASR 使用 | P0 | 抽取成功率 100%（常规片源）；异常编码有明确报错 | F-M1-01 |
| F-M1-03 | ASR 语音识别 | faster-whisper 生成逐行时间轴与原文；模型大小（small/medium/large-v3）与源语言可配 | P0 | 日语单集在 RTX 3060 上转录 ≤ 5min；时间轴误差人耳无感（±200ms 内） | F-M1-02 |
| F-M1-04 | LLM 翻译引擎 v1 | OpenAI 兼容多渠道接入（base_url/key/model 可配）；分批翻译 + 前后文窗口；JSON 结构化输出与行号容错；指数退避重试 | P0 | 至少接入 2 家 OpenAI 兼容渠道验证通过；输出行数 = 输入行数；模拟超时/断网可重试并最终明确报错 | F-M1-03 |
| F-M1-05 | 全局术语表 | 手动维护词条（原文/译文/备注），翻译时命中注入 prompt | P0 | 命中词条的行译文与术语表一致 | F-M1-04 |
| F-M1-06 | SRT 导出 | 导出单语（中文）与双语（日上中下）SRT | P0 | 时间轴与原文逐行对应；常见播放器（VLC/PotPlayer）加载正常 | F-M1-04 |
| F-M1-07 | 流水线任务与状态 | Stage 状态机（ingest→asr→translate→subtitle→export）；进度查询；失败原因展示；单 Stage 重试 | P0 | Job 重跑已成功 Stage 不重复执行；失败 Stage 可单独重试成功 | F-M1-02 |
| F-M1-08 | 基础 Web UI | 项目列表、视频上传、任务进度、字幕表格预览、下载；浅色主题即可 | P0 | 全流程（上传→出字幕→下载）无需命令行操作 | F-M1-07 |
| F-M1-09 | Docker Compose 一键部署 | api + web + 数据卷；模型下载说明文档 | P0 | 全新机器 `docker compose up` 后按文档完成配置即可使用 | 全部 |

**M1 出口标准**：一集 24 分钟日文生肉，30 分钟内（含等待）产出可读的中文双语 SRT。

## 3. M2 · 字幕工程与翻译质量（v0.2）

| ID | 功能点 | 描述 | 优先级 | 验收标准 | 依赖 |
|---|---|---|---|---|---|
| F-M2-01 | ASS 导出与样式模板 | 默认"底部对白+顶部注释"双样式；字体/字号/描边/边距可配；项目级自定义模板 | P0 | 默认模板在常见分辨率下渲染正确；模板可保存复用 | F-M1-06 |
| F-M2-02 | 双轮翻译 | S4 初翻 → S5 润色；两轮可配置不同模型；项目级开关 | P0 | 开启双轮后抽样对比，口语自然度显著优于单轮；单轮模式不受影响 | F-M1-04 |
| F-M2-03 | 番剧级术语表与角色表 | 术语按项目隔离；角色表（日文名/中文名/别名/备注）注入翻译；术语锁定 | P0 | 同一角色名全季译法一致；锁定词条重跑不漂移 | F-M1-05 |
| F-M2-04 | Bangumi 元数据集成 | 按番剧名搜索 Bangumi，拉取话数/角色/CV，自动生成术语与角色建议，人工确认后生效 | P1 | 主流新番可检索匹配；确认后词条自动进入项目术语表 | F-M2-03 |
| F-M2-05 | 硬字幕 OCR 流程 | 场景检测抽帧 → PaddleOCR → 跨帧去重，产出 signs 屏幕文字轨并参与翻译与导出 | P1 | 常见内嵌字幕片源可识别出主要对白字幕行；识别结果标记置信度 | F-M1-02 |
| F-M2-06 | 整季批量任务 | 多集任务队列、并发数可配、失败自动重试与手动重跑、批量导出 | P0 | 12 集批量提交后无人值守跑完；失败集不影响其他集 | F-M1-07 |
| F-M2-07 | 时间轴自动校正 | 重叠消除、最小间隙、最短显示时长、超长智能拆行 | P1 | 校正后质检零时间轴类告警 | F-M1-06 |
| F-M2-08 | QA 质检报告 | CPS/重叠/空译/术语一致性/格式规则检查，产出可逐条跳转的告警清单 | P0 | 人工构造的违规样例全部命中；点击告警可定位到行 | F-M1-06 |
| F-M2-09 | 已有字幕导入翻译 | 上传 SRT/ASS 跳过 ASR 直接进翻译 Stage | P1 | 日文 SRT 导入后翻译导出，时间轴不变 | F-M1-04 |
| F-M2-10 | 译文缓存与成本优化 | segment 级译文缓存（原文+模型+prompt 版本）；token 用量与费用估算展示 | P1 | 同源重跑翻译 Stage 时 LLM 调用次数为 0（命中缓存） | F-M1-04 |

**M2 出口标准**：整季批量跑完 + QA 报告，人工工作量集中在校对而非打轴。

## 4. M3 · 人工复核工作台与团队协作（v1.0）

| ID | 功能点 | 描述 | 优先级 | 验收标准 | 依赖 |
|---|---|---|---|---|---|
| F-M3-01 | 字幕复核工作台 | 三栏布局：视频预览（artplayer）+ 字幕表格 + 上下文面板；行点击视频跳转、行内编辑、时间轴微调；快捷键 | P0 | 逐行校对全程不碰键盘外的工具；快捷键覆盖高频操作 | F-M1-08 |
| F-M3-02 | 波形图对轴 | wavesurfer 波形叠加字幕区间，拖拽微调起止点 | P2 | 对轴精度可人工校至 ±50ms | F-M3-01 |
| F-M3-03 | 审核流状态机 | 行级状态 draft→translated→reviewed→final；行锁定；集级审核进度 | P0 | 状态流转有记录（review_record）；锁定行 AI 重跑不覆盖 | F-M3-01 |
| F-M3-04 | 用户与权限 | 账号体系，角色：管理员/翻译/校对；JWT 鉴权 | P1 | 角色越权操作被拒绝并提示 | F-M3-03 |
| F-M3-05 | 任务系统升级 | Celery + Redis 独立 worker；GPU 任务标签路由；WebSocket 进度推送 | P1 | worker 重启后任务可恢复；GPU/CPU 任务分节点执行 | F-M1-07 |
| F-M3-06 | 存储升级 | SQLite→PostgreSQL；本地文件→MinIO；提供迁移脚本 | P1 | M1/M2 数据可无损迁移 | — |
| F-M3-07 | 翻译记忆 | 相似句检索（翻译记忆库），历史译文作为参考注入 | P2 | 相似度 ≥90% 的历史句自动带出参考译文 | F-M2-02 |
| F-M3-08 | 成品导出 | 软字幕封装 MKV（挂 ASS 轨）/ 硬压 MP4（libass） | P0 | 封装/硬压成品字幕渲染与预览一致；硬压耗时给出进度 | F-M2-01 |
| F-M3-09 | 成本与操作看板 | 项目级 token/费用统计、任务历史、操作日志 | P2 | 费用估算与渠道账单误差可解释（±20%） | F-M2-10 |

**M3 出口标准**：字幕组三人（翻译/校对/终审）协作完成一集全流程，无需切换任何外部工具。

## 6. 版本发布策略

- 每个里程碑合并主干后打 tag 发布（v0.1 / v0.2 / v1.0 …），附 Docker 镜像与更新说明。
- v1.0 前允许破坏性 Schema 变更（提供重置脚本）；v1.0 起变更必须带数据迁移脚本。
- 每个 P0 功能点必须有自动化测试覆盖核心路径（流水线状态机、翻译容错、时间轴校正）。
